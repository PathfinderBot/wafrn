Migrating from Bluesky is relatively easy, but requires your attention!

Let's get some prerequisites out of the way:

  • If you're currently using a wafrn-hosted bsky account, it will be nuked.
  • This doesn't always go smoothly! If any issues occur, reach out to the wafrn team!
  • If you are using a .bsky.social handle, it will be moved to .{{ environment().bskyPDSUrl }}
  • You cannot use your own PDS. You will be using the Wafrn-hosted one.

When you're ready, continue here:

 Unlinking and deleting the old account

First off, we must unlink (and delete) your previous linked bluesky account. This is the Wafrn-hosted one, if you have one.

This will also give you an "invite code", that we'll use in the next steps to move over your existing account. Please write it down!

 PDSMoover - Actually moving the account

Now we'll use an external migration tool, called PDS Moover to do the actual migration part.

For the provider, give them this URL: {{ environment().bskyPDSUrl }}

Follow their instructions closely. If something goes wrong, reach out to the Wafrn team and your site admin!

And of course, give PDS Moover the invite code that you wrote down

You wrote it down, right? If not, go back.

 Linking the account to Wafrn

If the "MOOVE" went alright, we'll now need to link up the migrated account to Wafrn.

To do this, we log in to the newly migrated account as if it was any other Bluesky account on bsky.app, and create an "App Password"

You'll find the relevant options in Settings > Privacy and Security > App Passwords

Once you've grabbed a new app password, put it in together with the new username here:
